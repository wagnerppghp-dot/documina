# Documina

Site oficial do **Documina**, aplicativo desktop que transforma PDFs em Markdown, Word, JSON e TXT com privacidade e processamento local.

## Site

Esta landing page foi construída com HTML, CSS e JavaScript puros e está pronta para publicação pelo GitHub Pages.

## Produto

- Conversão simultânea para MD, DOCX, JSON e TXT.
- Preservação do PDF original.
- Biblioteca local organizada.
- Processamento offline e privado.
- Interface em português e inglês.

**Documina — Documentos em conhecimento.**
